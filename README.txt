CLAUDE CODE LAUNCHER
====================

Удобное меню для запуска Claude Code в Windows:
  - недавние проекты с поиском (берутся из истории Claude Code);
  - в проекте: новая сессия, продолжить последнюю, любая из недавних, список всех;
  - лимиты подписки (5 часов и неделя) прямо в меню и строкой над полем ввода в Claude;
  - настройки: модель, режим разрешений, язык (русский / English) и другое;
  - «Сведения и лимиты»: аккаунт, план, лимиты и версии программ;
  - обновления из GitHub: лаунчер сам сообщает о новой версии и ставит её;
  - каталог скиллов для Claude Code: установка в один щелчок;
  - «Проверка компонентов»: если чего-то нет на компьютере, лаунчер скажет, что именно,
    где искал и как это исправить (или скачает недостающие файлы сам);
  - мышь: щелчок по пункту открывает его, колесо листает список.


УСТАНОВКА
---------
1. Нужен установленный Claude Code. Если его нет, лаунчер сам предложит поставить
   официальный установщик при первом запуске.
2. Распакуйте архив в любую папку.
3. Дважды щёлкните Install.cmd.
4. На рабочем столе и в меню «Пуск» появится ярлык «Claude Code Launcher».

Если Windows спросит «Запустить этот файл?», нажмите «Подробнее → Выполнить в любом случае»
(файлы скачаны из интернета, поэтому Windows переспрашивает).

Лучше всего лаунчер выглядит в Windows Terminal (в Windows 11 он уже есть, в Windows 10 его
можно поставить из Microsoft Store). Без него откроется обычное окно консоли попроще.


УПРАВЛЕНИЕ
----------
  стрелки ↑ ↓          выбор
  Enter                открыть / запустить
  буквы                поиск проекта на главном экране
  Delete               скрыть проект из списка (вернуть: Настройки)
  N  C  R  O           в проекте: новая / продолжить / все сессии / открыть папку
  ← →                  в настройках: поменять значение
  Esc                  назад
  мышь                 щелчок открывает пункт, колесо листает


ЛИМИТЫ
------
Лимиты приходят от самого Claude Code, поэтому появляются после первого ответа Claude
в сессии, запущенной из лаунчера. Работают только при входе по подписке (Pro / Max).
Для этого лаунчер подключает к своим сессиям два маленьких мода (папки usage-mod и limits-bar).
Оба можно выключить в настройках.


ОБНОВЛЕНИЯ
----------
При запуске лаунчер тихо проверяет GitHub-репозиторий. Если вышла новая версия, на главном
экране появляется «Вышло обновление» и пункт «Обновить лаунчер»: там список изменений и кнопки
«Установить обновление», «Напомнить позже», «Пропустить эту версию». Файлы скачиваются,
сверяются по контрольным суммам и только потом заменяют старые.
Вручную: «Настройки → Проверить обновления». Репозиторий: «Настройки → Источник обновлений».


СКИЛЛЫ
------
«Настройки → Установить скиллы» показывает скиллы из того же репозитория. Enter ставит или
обновляет скилл в ~/.claude/skills, Delete удаляет (только поставленные из лаунчера).
Claude Code увидит новый скилл в следующей сессии.


ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ
---------------------
Сначала откройте «Настройки → Проверка компонентов» (если проблемы есть, этот пункт появится
и на главном экране). Там видно, чего не хватает и где лаунчер это искал, и есть кнопки
исправления: скачать недостающие файлы, установить Claude Code или Git, пересоздать ярлыки,
сбросить повреждённые настройки, скопировать отчёт, чтобы отправить его тому, кто поможет.
Если лаунчер упал с ошибкой, её текст останется на экране и будет скопирован в буфер обмена.

Дважды щёлкните Repair.cmd: откроется Claude Code с инструкцией REPAIR.md, он сам найдёт
и исправит проблему. То же самое есть в меню: «Настройки → Что-то сломалось? Починить с Claude».
Текст промта можно скопировать («Настройки → Скопировать промт для починки») и вставить
в Claude Code или на claude.ai.


УДАЛЕНИЕ
--------
Uninstall.cmd или «Настройки → Удалить лаунчер».
Claude Code и история ваших сессий остаются на месте.

Где лежит: %LOCALAPPDATA%\ClaudeCodeLauncher


ДЛЯ АВТОРА: КАК ВЫПУСТИТЬ ОБНОВЛЕНИЕ
------------------------------------
1. Поднимите $AppVersion в начале launcher.ps1 (например, 2.0.0 → 2.0.1).
2. Добавьте запись в начало changelog.json (version, date, ru[], en[]) — это «Что нового».
3. Скиллы для каталога кладите в папку skills\<имя>\SKILL.md.
4. Соберите манифест:  powershell -NoProfile -ExecutionPolicy Bypass -File tools\Make-Manifest.ps1
5. Закоммитьте и отправьте в ветку main репозитория. Через несколько минут лаунчеры увидят версию.
Репозиторий должен быть публичным. Его адрес задаётся в $DefaultSource в начале launcher.ps1.
