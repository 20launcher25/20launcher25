# Политика использования Claude Code Launcher

**Русский** · [Қазақша](POLICY.kk.md) · [English](POLICY.en.md)

*Действует с 23 ноября 2026 г.*

## 1. Что это

Claude Code Launcher это бесплатная программа-меню для запуска [Claude Code](https://docs.claude.com/en/docs/claude-code/overview) в Windows. Её поддерживает организация [20launcher25](https://github.com/20launcher25).

Это **неофициальный** проект: Anthropic его не создавала, не проверяла и не поддерживает. «Claude» и «Claude Code» являются товарными знаками Anthropic и упоминаются только для того, чтобы назвать программу, с которой работает лаунчер.

## 2. Условия использования

- Пользоваться лаунчером можно бесплатно, и дома, и на работе.
- Работа с Claude Code через лаунчер остаётся работой с Claude Code, поэтому для неё действуют [условия Anthropic](https://www.anthropic.com/legal) и [правила использования](https://www.anthropic.com/legal/aup). Лаунчер их не меняет и не обходит. Лимиты подписки он только показывает и никак не увеличивает.
- Нельзя использовать лаунчер и его скиллы для действий, которые нарушают закон или правила Anthropic.
- Делитесь лаунчером ссылкой на этот репозиторий. Не выдавайте изменённые копии за официальную версию 20launcher25 и не распространяйте их под тем же названием.

## 3. Какие данные он использует

Лаунчер работает на вашем компьютере и **ничего о вас не отправляет**. Аналитики и телеметрии в нём нет.

| Что | Зачем | Куда уходит |
| --- | --- | --- |
| История сессий Claude Code (`~/.claude/projects`) | список недавних проектов и сессий | никуда, только чтение |
| Данные аккаунта из `~/.claude.json` (имя, почта, план) | экран «Сведения и лимиты» | никуда, только чтение |
| Лимиты подписки (файл пишет мод `usage-mod`) | полоски лимитов | никуда |
| Настройки лаунчера (`%LOCALAPPDATA%\ClaudeCodeLauncher`) | ваши настройки | никуда |

В интернет лаунчер обращается только сам и только сюда: скачивает `manifest.json`, обновления и скиллы из этого репозитория (`raw.githubusercontent.com`). Как и любой сайт, GitHub видит при этом ваш IP-адрес. Автопроверку можно выключить: «Настройки → Проверять при запуске».

## 4. Обновления и скиллы

- Каждый файл обновления или скилла перед установкой сверяется с контрольной суммой SHA-256 из `manifest.json`. Записывать файлы за пределами папки лаунчера или папки скилла лаунчер не умеет.
- Скиллы из каталога являются инструкциями для Claude. Устанавливая скилл, вы разрешаете Claude ими пользоваться, поэтому сначала прочитайте его описание.
- Менять репозиторий могут только сопровождающие. Предложения от других людей принимаются через pull request после проверки (раздел 6).

## 5. Ответственность

Программа предоставляется **«как есть»**, без гарантий. Сопровождающие не отвечают за потерю данных, расход лимитов подписки и последствия действий Claude, запущенного через лаунчер. Режимы, в которых Claude действует без вопросов («сам правит файлы», «авто»), вы включаете на свою ответственность.

## 6. Как предложить изменение или сообщить о проблеме

- Ошибки и идеи присылайте в [Issues](https://github.com/20launcher25/20launcher25/issues). Приложите отчёт: «Настройки → Проверка компонентов → Скопировать отчёт». В нём только версии и пути к файлам, но перед отправкой всё же прочитайте его.
- Код или скилл предлагайте через fork и pull request. В ветку `main` он попадёт только после одобрения сопровождающего.
- Об уязвимостях не пишите в открытые Issues, используйте [Security → Report a vulnerability](https://github.com/20launcher25/20launcher25/security).

## 7. Изменения политики

Новая редакция публикуется в этом файле, все правки видны в истории коммитов. Продолжая пользоваться лаунчером после изменения, вы соглашаетесь с новой редакцией.
